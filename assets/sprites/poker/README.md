# DeetsPoker chip sprites

Edge-on chip art for the poker tab (docs/poker.md, "Chips on the table").
A stack is one **side** sprite per chip, tiled the whole way up. There is
deliberately **no top-of-stack face sprite** — a face capping a column of
bands read as odd (his call, chat 2026-08-03), so every chip in a stack
is the same side view.

`poker/poker.js` probes all five files ONCE at page load and swaps art in
over the CSS placeholder the moment a file exists — draw over these
templates one at a time and only that chip changes. Deleting a file falls
back to the placeholder for that rank.

## Naming scheme (exact, all lowercase)

| file | chip |
| --- | --- |
| `chip-side-{1..5}.png` | one chip, edge-on: the band |

**The number is the chip's RANK in the ladder, not its value.** Values are
derived from the buy-in (docs/poker.md, "The settings cascade") — a $20
table's rank-1 chip is 10¢ and a $100 table's is 50¢ — but rank 1 is
always the smallest chip on any table, and always white. That is what
makes these filenames stable. Ranks 6-8 exist only on a hand-built ladder
and keep the CSS placeholder.

Rank colors (`RANK_HEX` in `poker/transport-mock.js`), if you want to stay
on palette:

| rank | color | hex |
| --- | --- | --- |
| 1 | white | `#f2efe6` |
| 2 | red | `#d94141` |
| 3 | green | `#2fae66` |
| 4 | blue | `#3b7dd8` |
| 5 | black | `#26221f` |

## Canvas

Templates are **96 × 24** — 4× the 24 × 6 the rail draws at, 6× the
felt's 16 × 4. As with the mahjong tiles the page downscales with plain
smooth filtering (**no `image-rendering: pixelated`** — at fractional
sizes nearest-neighbor makes identical chips shimmer against each other,
and a stack is nothing but identical chips), so ship at 4× and it stays
crisp at both sizes and on HiDPI.

Draw the WHOLE chip — band, spots, edges — the image fully replaces the
placeholder's styling. The sprite **tiles vertically**, so its top and
bottom edges must meet cleanly: whatever you draw on the very top row
sits directly against the bottom row of the chip above it. A stack is
this one image repeated, nothing else.

The templates are generated by `scripts/build-poker-chips.py`
(**re-running it RESETS the folder** — don't, once hand art has landed).
